# Реестр полезных ссылок

Локальный веб-реестр ссылок с поддержкой тем, плагинов, категорий, тегов,
корзины, экспорта и статистики. Работает на Flask + openpyxl, данные
хранятся в Excel-файле `реестр.xlsx`.

## Быстрый старт

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Запустить
python app.py

# 3. Открыть в браузере
http://127.0.0.1:5432
